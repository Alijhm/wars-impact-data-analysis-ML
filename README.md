# wars-impact-data-analysis-ML

## Présentation du Projet
Ce projet personnel explore l'impact humanitaire, social et économique des conflits armés à travers trois contextes : **l'Ukraine**, **l'Irak** et **la Bosnie-Herzégovine**. L'objectif est d'analyser les corrélations entre l'intensité des combats et plusieurs indicateurs clés (PIB, espérance de vie, flux de réfugiés), puis de tester un modèle de classification simple (Random Forest) pour identifier les chocs économiques.
